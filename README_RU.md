###### **ОБЗОР**

Morse Beeper v2.0 — это простой скрипт на Python, предназначенный для практики или прослушивания временных интервалов и аудиосигналов азбуки Морзе. Он перехватывает нажатия клавиш в режиме реального времени, воспроизводит звуковые сигналы, соответствующие тире («—») и точкам («·») с помощью встроенного звукового синтезатора Windows, и выводит символы на экран.



###### **ВОЗМОЖНОСТИ**

* Перехват нажатий клавиш в режиме реального времени с использованием глобальных горячих клавиш.
* Отображение вводимых символов Морзе в консоли в реальном времени.
* Вставка пробела для разделения знаков и слов.
* Функция очистки экрана прямо во время работы.
* Несколько режимов скорости, основанных на количестве слов в минуту (WPM):
  * Режим 1: Очень медленный (~5 WPM)
  * Режим 2: Стандартный (~12 WPM)
  * Режим 3: Быстрый (~20 WPM)
* Поддержка двух раскладок клавиатуры (например, стандартная раскладка и кириллица/альтернативное сопоставление для клавиш «j» / «k» и «-» / «.»).
* Простой механизм выхода с помощью клавиши ESC.



###### **ТРЕБОВАНИЯ**

* Операционная система Windows (используется модуль `winsound`)
* Python 3.x
* Пакет `keyboard` (Установка: `pip install keyboard`)
* *Примечание: Для запуска скриптов с горячими клавишами `keyboard` в Windows могут потребоваться права администратора.*



###### **ИСПОЛЬЗОВАНИЕ**

1. Запустите скрипт:
[Morze_Beeper.py](Morze_Beeper.py)
2. Выберите режим скорости, введя 1, 2 или 3 при появлении запроса. Если выбран неверный вариант, по умолчанию устанавливается Стандартный режим (12 WPM).
3. Управление:
   * Нажмите «j» или «-», чтобы воспроизвести ТИРЕ («—»).
   * Нажмите «k» или «.», чтобы воспроизвести ТОЧКУ («·»).
   * Нажмите «Пробел», чтобы вставить пробел.
   * Нажмите «c», чтобы очистить экран и сбросить вывод.
   * Нажмите «ESC» для выхода из приложения.
